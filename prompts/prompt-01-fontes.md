# Prompt 01 — Curadoria das Fontes

## Objetivo

Identificar, organizar e comparar as fontes adicionadas ao NotebookLM
para selecionar os materiais mais relevantes para o estudo de ransomware.

## Prompt utilizado

Estou desenvolvendo um caderno temático sobre ataques de ransomware
para um projeto de estudo em Segurança da Informação.

Analise todas as fontes adicionadas a este notebook e crie uma tabela
comparativa contendo:

1. Nome da fonte;
2. Autor ou instituição responsável;
3. Ano de publicação, quando disponível;
4. Tipo de fonte (artigo, relatório, guia, documento técnico etc.);
5. Principais assuntos abordados;
6. Qual contribuição essa fonte oferece para o estudo de ransomware;
7. Nível de relevância para o meu projeto: Alta, Média ou Baixa.

Não invente informações. Quando uma informação não estiver disponível
nas fontes, indique "não informado".

Ao final, recomende quais 3 a 5 fontes são mais adequadas para serem
utilizadas como referências principais no projeto e justifique a escolha.
